# iromon

架空のエナジードリンク「iromon」のLP(ランディングページ)サイトです。
フリーランスを目指した学習の一環として、レスポンシブ対応とインタラクションの実装を行いました。

## Demo

https://minami-works.github.io/iromon/

## 使用技術

- HTML5
- SCSS(BEM命名規則 / パーシャル分割)
- JavaScript(Vanilla JS)
- Git / GitHub Pages

## こだわったポイント

- **Figmaのカンプと数値で照らし合わせた実装**
  カンプの座標・サイズと照らし合わせて、コンテンツ幅(1440pxで左右80px)、ボタンの矢印位置、Flavorカードの文字・星の位置、hover色などを数値で一致させました。
- **カンプにない中間幅の設計(768px〜1339px)**
  カンプは375px(SP)・1440px(PC)の2種類のみだったため、中間幅は自分で設計しました。特にFlavorカードは、中身が収まる幅を測ったうえで4段階に切り替えています。
  - 〜767px：SPのカード(1列)
  - 768〜1099px：SPのカードを最大360pxで2列
  - 1100〜1339px：PCのカードを400px固定で2列(3列だと星が潰れるため)
  - 1340px〜：PCのカードで3列
- **どの画面幅でも崩れないための工夫**
  - `padding` / `margin` の `%` が「幅」基準になる性質を使い、缶の画像と白い帯の重なりや、キャンペーン枠の余白を画面幅に比例させました
  - 画像は幅だけ `%` で指定して高さは `auto` にし、中間幅で縦横比が崩れないようにしました
  - 375〜1920pxの各幅で横スクロールが出ないことを確認しています
- **保守性を意識したコード設計**
  BEM命名規則とSCSSのパーシャル分割で、セクションごとにファイルを分離。ショートハンドプロパティを避け、個別プロパティで指定することで、意図しない上書きを防ぐようにしています。
- **JavaScriptによるインタラクション**
  - ハンバーガーメニューの開閉(リンクを押す／Escキーで閉じる、開いている間は背面のスクロールを止める)
  - Intersection Observer APIを使った、スクロール連動のフェードイン(3枚のカードを100msずつずらして表示)
  - CSS `@keyframes` によるループアニメーション(缶のフロート演出)
- **使う人への配慮**
  - `prefers-reduced-motion`(動きを減らす設定)のときは、移動やループのアニメーションを止めてフェードだけにしています
  - hoverの演出は `@media (hover: hover)` の中に書き、スマホでhoverの状態が残らないようにしています
  - JavaScriptが動かなかった場合でも、カードが非表示のままにならないようにしています

## つまずいた点・学んだこと

- `position: absolute` の子要素は、直近の `position` 指定祖先を基準に配置される(containing blockの考え方)
- `aspect-ratio` は要素自身の外側(border-box)の幅を基準に計算されるため、paddingを持つ親要素に設定すると意図しない縦横比のズレが起きる
- 縦方向の `margin` / `padding` の `%` 指定は、要素の高さではなく**幅**を基準に解決される
- 画像の `width` と `height` を両方 `%` で指定すると、幅は親の幅・高さは親の高さが基準になるため、画面幅によって縦横比が崩れる
- SVGを `<img>` で表示すると、枠の縦横比が違っても絵は縦横比を保って枠に収まる(そのため枠のサイズを測っても、実際に描かれる絵の大きさとは一致しない)
- `@media` の幅にはスクロールバー(約15px)も含まれるため、ブレークポイントの境目では余裕を持たせる必要がある

## Note

本サイトのデザイン・イラスト素材は、参加したセミナーにて配布されたものを使用しています。

初回のコーディング(HTML/SCSS/JS)は全て自身で実装しました。その後、AI(Claude Code)を使ってカンプとの差分や中間幅での崩れを洗い出し、プレビューで修正内容を確認・判断しながら改修しています(「こだわったポイント」の中間幅の設計やカンプとの照合は、この改修で行ったものです)。
