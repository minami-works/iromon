# iromon

架空のエナジードリンク「iromon」のLP(ランディングページ)サイトです。
フリーランスを目指した学習の一環として、レスポンシブ対応とインタラクションの実装を行いました。

## Demo

https://minami-works.github.io/iromon/

## 使用技術

- HTML5
- SCSS(BEM命名規則 / パーシャル分割)
- JavaScript(Vanilla JS)
- Git / GitHub Pages

## こだわったポイント

- **モバイルファーストのレスポンシブ設計**
  デザインカンプが375px(SP)・1440px(PC)の2種類しかなかったため、768px〜1099pxの中間ブレークポイントは自分で設計・実装しました。
- **保守性を意識したコード設計**
  BEM命名規則とSCSSのパーシャル分割で、セクションごとにファイルを分離。ショートハンドプロパティを避け、個別プロパティで指定することで、意図しない上書きを防ぐようにしています。
- **JavaScriptによるインタラクション**
  - ハンバーガーメニューの開閉
  - Intersection Observer APIを使った、スクロール連動のフェードイン・スライドインアニメーション
  - CSS `@keyframes` によるループアニメーション(缶のフロート演出)

## つまずいた点・学んだこと

- `position: absolute` の子要素は、直近の `position` 指定祖先を基準に配置される(containing blockの考え方)
- `aspect-ratio` は要素自身の外側(border-box)の幅を基準に計算されるため、paddingを持つ親要素に設定すると意図しない縦横比のズレが起きる
- 縦方向の `margin` / `padding` の `%` 指定は、要素の高さではなく**幅**を基準に解決される
